    Subcapturing #

    Subcapt Γ C1 C2 defines the subcapturing judgement Γ ⊢ C1 <: C2 in Fig. 2. Most rules correspond directly to the rules on the paper. The Subcapt.cinstl and Subcapt.cinstr rules are for capture set variables bound by Term.bindc--they are transparent in the subcapturing relation.

    source
    inductive Capless.Subcapt {n m k : ℕ} :
    Context n m k → CaptureSet n k → CaptureSet n k → Prop
    • trans {n m k : ℕ} {Γ : Context n m k} {C1 C2 C3 : CaptureSet n k} : (Γ ⊢ C1 <:c C2) → (Γ ⊢ C2 <:c C3) → Γ ⊢ C1 <:c C3
    • subset {n m k : ℕ} {C1 C2 : CaptureSet n k} {Γ : Context n m k} : C1 ⊆ C2 → Γ ⊢ C1 <:c C2
    • union {n m k : ℕ} {Γ : Context n m k} {C1 C3 C2 : CaptureSet n k} : (Γ ⊢ C1 <:c C3) → (Γ ⊢ C2 <:c C3) → Γ ⊢ C1 ∪ C2 <:c C3
    • var {n m k : ℕ} {Γ : Context n m k} {x : Fin n} {C : CaptureSet n k} {S : SType n m k} : (Γ.Bound x S ^ C) → Γ ⊢ {x=x} <:c C
    • cinstl {n m k : ℕ} {Γ : Context n m k} {c : Fin k} {C : CaptureSet n k} : Γ.CBound c (CBinding.inst C) → Γ ⊢ C <:c {c=c}
    • cinstr {n m k : ℕ} {Γ : Context n m k} {c : Fin k} {C : CaptureSet n k} : Γ.CBound c (CBinding.inst C) → Γ ⊢ {c=c} <:c C
    • cbound {n m k : ℕ} {Γ : Context n m k} {c : Fin k} {C : CaptureSet n k} : Γ.CBound c (CBinding.bound (CBound.upper C)) → Γ ⊢ {c=c} <:c C
