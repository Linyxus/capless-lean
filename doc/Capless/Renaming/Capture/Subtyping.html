    Capture Variable Renaming for Subtyping #

    This module proves that subtyping relationships are preserved under capture variable renaming. It provides theorems showing that SSubtyp, CSubtyp, and ESubtyp judgments are preserved when capture variables are renamed consistently between contexts.
